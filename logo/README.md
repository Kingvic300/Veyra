# Veyra logo

The mark is a "V" made of two settlement strokes that meet at a block: the point where a payment becomes final. The source of truth is `apps/dashboard/src/components/logo.tsx`; these files are exports of it.

## Files

| File | Use |
|---|---|
| `veyra-logo.svg` | Mark and wordmark, for light backgrounds |
| `veyra-logo-white.svg` | Mark and wordmark, for dark backgrounds |
| `veyra-mark.svg` | Mark only (app icon, avatar, favicon) |
| `veyra-mark-light.svg` | Mark only, for dark backgrounds |
| `veyra-wordmark.svg` | Wordmark only |
| `png/` | PNG exports: mark at 32 to 1024 px, logos at 8x |

The wordmark is converted to outlines, so the SVGs render the same without the font installed.

## Colours

| Name | Hex |
|---|---|
| Ink | `#13201b` |
| Settle | `#0b6b4f` |
| Settle wash | `#e3f1eb` |
| Block | `#3fbf8f` |

## Type

Schibsted Grotesk, weight 600, letter spacing -0.02em.

Leave clear space around the logo of at least half the mark's height. Do not recolour, stretch or rotate it.
